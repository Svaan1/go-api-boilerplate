## Orchestration

You orchestrate. Do the planning and thinking and delegate mechanical work
to subagents. Briefs must be exact and self-contained. No open-ended asks,
no room for subagents to explore or decide. If something doesn't match,
they stop and report. Don't delegate judgment, debugging, or tasks smaller
than the brief. Run independent subagents in parallel when possible.

## Skills

Use all relevant available skills for every task. Treat skill instructions as coding guidelines and requirements, not suggestions. Follow them throughout planning, implementation, and review.

## Tests

- Tautological tests considered harmful.
- Change-detector tests considered harmful.
- Do not create regression tests for bug fixes without a genuine gap in behavior testing.
